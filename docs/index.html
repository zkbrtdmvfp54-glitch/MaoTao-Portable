03 · 隐私承诺

它听得见键盘，
所以先说清楚

桌面宠物常驻屏幕角落，安全与透明是最基本的底线。毛桃纯本地离线运行，主进程主动拦截一切外网请求。

01
纯内存驱动动画，绝不记录输入文本

跨应用键鼠联动默认关闭，需你手动确认开启；开启后仅在内存中识别左右手区域与动作类别，松手即弃，不读取、不保存、不上传任何打字内容。

02
100% 本地离线，零统计零遥测

Electron 主进程主动阻断所有外部网络访问，无需登录账号，不包含任何埋点、广告或云端同步；网页试玩版同样完全在你的浏览器本地运行。

03
一键切换隐私模式与点击穿透

输入密码或录屏时，随时按 Alt+Shift+P 进入隐私模式（仅随机抬爪，不点亮具体键位），按 Alt+Shift+L 锁定点击穿透，完全不挡手。

04 · 常见问题

安装、权限与快捷键，
一页看清

个人独立开发项目暂未购买商业代码签名证书，首次运行遇到系统安全提示属于正常现象。

01 Windows 提示“已保护你的电脑”怎么办？ +
因未购买商业 EV 签名证书，Windows SmartScreen 首次打开会弹出蓝色提示。点击弹窗中的「更多信息」→「仍要运行」即可正常启动。推荐优先下载便携版（Portable），免安装双击即用。
02 macOS 提示“无法验证开发者 / 已损坏”？ +
将应用拖入「应用程序」文件夹后，打开「终端」执行一次下方命令移除隔离标记，即可正常打开：
xattr -cr "/Applications/MAOTAO Desktop Pet.app"
03 macOS 跨应用打字联动需要什么权限？ +
首次开启跨应用键鼠联动时，请前往「系统设置 → 隐私与安全性 → 输入监控」勾选 MAOTAO Desktop Pet 并重启应用即可生效。
04 麒麟 / Linux 支持哪些桌面环境？ +
提供 x64 .AppImage 与 x64 / ARM64 .deb 安装包。在 X11 会话下支持全局键鼠联动与窗口置顶；Wayland 会话下会自动禁用全局钩子，窗口内本地互动与专注模式均可正常使用。
05 如何防止误点小猫或找回拖出屏幕的小猫？ +
玩游戏或全屏看视频时，按 Alt+Shift+L 可一键锁定点击穿透；右键系统托盘图标可随时选择「居中」或「复位到主屏」找回小猫，也可随时打开三栏暖纸风控制面板。
