# 毛桃角色画风约束

## 角色模型

- 直接沿用当前程序中的 7paws 程序化 3D 身体、头部、四肢、尾巴和键鼠场景，继续使用同一套动作与输入映射。
- 黑猫是统一的造型基准。所有花色共用相同的头身比例、面部布局、四肢长度、爪子位置与动作；花色只通过毛色、贴纹和眼睛颜色变化。
- 角色面部不绘制嘴部结构，也不在打哈欠或待机动作中出现嘴部图形。保留参考图中的小鼻点、圆环眼、眨眼和瞳孔追踪。
- 六种花色均绘制同尺寸的小鼻点：纯黑猫用白色，暹罗用暖棕色，奶牛猫、三花、毛桃虎斑和异瞳白猫使用低饱和粉色。鼻点随头部模型变形与转动，不用单独漂浮的 2D 色块。
- 采用近似平涂的暗色剪影、圆润头身、清晰尖耳、简洁尾巴和低细节密度。胸口与四肢的内部接缝保持很细、很暗，不能表现成单独伸出的线段。
- 不使用生图角色图或整动作图集替代运行中的角色模型。备用 2D 路径使用无面部嘴线的本地矢量剪影。

## 动作与反馈

- 鼠标持续移动时，眼睛优先追随桌面指针；指针停下且正在打字时，视线转向实际敲击的键位。
- 键位视线以最近一次实际击中的键位为目标；两侧键产生不同方向。鼠标重新移动后立即取代键位目标。
- 保留键盘双爪敲击、鼠标爪位、快速输入怒气反馈和拍尾动作。
- 待机时保留呼吸、耳朵、尾巴、转头等轻动作；偶尔显示毛线球并让小猫追玩。球出现时可直接点击，触发一段追玩动作。
- 专注模式显示 25 分钟计时与鼠标绿色耳机，并暂停随机玩球动作；真实键鼠反馈继续工作。
- 宠物闲置复合画面以约 33 FPS 更新，输入或动作活跃时以约 66 FPS 更新；3D 模型持续按显示器刷新率绘制。
