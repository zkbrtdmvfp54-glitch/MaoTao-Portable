# Phase 0 · 源码与素材审查

## 原型

只读原型为 `reference/code_artifact.html`，2456 行；项目根目录保留收到的原文件。原型可在浏览器中运行，包含绘本场景、`StorybookSound`、`CatFacingKeyboard`、`SiameseCatPet`，以及本地按键/鼠标响应、双爪敲击、抚摸、戳击、拖动、休眠唤醒、每日计数与浮字效果。原网页依赖 CDN 样式和字体，键鼠监听仅覆盖网页获得焦点时。

## 素材和本轮角色决策

`assets/pet/reference/` 保留原始的猫、键盘、鼠标素材、角色参考和用户提供的 `maotao-shortcut-logo.png`。应用角色以 GitHub `7wdn/7paws` 的源码和模型为基础，参考图用于校准配色，角色仍由模型和本地渐变纹理渲染；原始用户猫图只作为 WebGL 初始化失败时的备用素材。参考图片不进入发行包；快捷栏原图会生成 `processed/app.ico` 与 `processed/tray.png` 并用于应用图标和托盘。

7paws 的键盘和鼠标场景成为正常模式的桌面；隐藏键帽上的字母标签，保留空格键和原键盘布局，鼠标没有鼠标垫。普通空格事件会给模型键盘两侧发送同时按压信号，表现为双爪敲击。托盘提供奶牛猫、三花猫、暹罗猫、灰白虎斑毛桃、异瞳白猫和纯黑白爪猫六种配色，默认毛桃；只有虎斑猫使用“毛桃”这个角色名。所有花色均无嘴并带鼻点：纯黑猫白鼻点、暹罗暖棕鼻点，其余为低饱和粉色。奶牛猫白色开脸是肚皮同色、边缘羽化的三角形；纯黑猫身体全黑并保留白色四爪。虎斑按最新优化图呈现银灰毛底、三道额纹、水平脸侧纹、浅色脸部与胸腹、四肢和环纹尾巴；面部和身体花纹均以渐变柔边融合。宠物模型整体缩至此前大小的 80%，键盘和鼠标尺寸不变。三花脸部橘黑色花纹软边晕染且保留白色中线；暹罗缩小棕色椭圆面罩，并对脸、前腿和尾部作渐变过渡，取消额部小点。快速打字触发靠近左耳的小型怒气符号、怒目和拍尾；待机时舔爪、摆尾，连续五分钟无键鼠活动后入睡。鼠标指针移动时优先追视，鼠标停下后近期键位作为次级视线目标。上游猫模型加宽身体、缩短躯干、扩大头部并调整爪腿比例，尽量靠近参考图的圆润坐姿。源码归档路径、精确上游提交及本地补丁见 `DEPENDENCY_AUDIT.md`。

## 功能迁移

| 原型职责 | 桌面实现 |
| --- | --- |
| `StorybookSound` | `SoundManager` 使用本地 Web Audio 合成按键、鼠标、猫叫与呼噜反馈；音效/单独键声开关和音量保存在设置中。 |
| `CatFacingKeyboard` | 按用户后续要求改用 7paws 的原生键盘场景和键位映射，不保留原型键盘插画；无键帽字母，保留空格双爪逻辑。 |
| `SiameseCatPet` | 行为/计时进入 `PetStateMachine`，命中与指针进入 `InteractionController`，角色场景渲染进入 `SevenPawsRenderer` 并由 `PetRenderer` 合成到透明画布。 |
| 页面壳 | `BrowserWindow` 透明悬浮、透明处穿透、可见区域点击、拖动、托盘、右键菜单与本地设置。 |
| 应用内键鼠输入 | 原有的类别/爪侧映射、按压动效、计数、提示与音效迁入事件状态机；跨应用模式只向角色层发送左右手和键鼠类别，不发送键值、文字或事件序列。 |

## 主要风险和边界

- 上游 7paws 角色保持其可动画的模型结构，角色造型和贴图针对参考图的坐姿比例及渐变毛色作本地调整；渲染仍是 7paws 的插画式风格，不是把参考图贴进窗口，也不是逐像素复刻其毛绒质感。
- WebGL 可用时显示 7paws 角色和键鼠；初始化失败时回退到用户原始猫图的本地 Canvas 显示。验收截图使用 WebGL 正常路径。
- 空格的双爪动作把第二爪映射到上游模型同一空格键的相对另一侧；不是外部键盘实际键位的逐帧手部捕捉。
- 原网页的外部 CDN、网页工具条、常驻输入框及鼠标垫绘制不进入常规桌面渲染路径。应用运行不需要远程资源。
